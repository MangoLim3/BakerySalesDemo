# BakerySalesDemo
This is my first public project, made by Google Colab
1. Open Google Colab
2. Create the new one
3. Open File on the up-left corner
4. Select Upload notebook
5. Upload the ipynb file named "prediksi_penjualan_bakery.ipynb"
6. Go to Files inside left column
7. click the upload button
8. upload XLSX (Don't rename it)
9. Run the whole code
